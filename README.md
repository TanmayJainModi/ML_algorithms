# ML_algorithms
This repository contains machine learning models for heart disease prediction using the Cleveland Heart Disease dataset. The project demonstrates implementation of both a custom logistic regression classifier and decision tree models.

# Models Implemented
Custom Logistic Regression

Decision Tree Classifier

Decision Tree Regressor

# Key Findings
Algorithm Implementation: Building machine learning algorithms from scratch to understand their inner workings

Feature Engineering: Analyzing which features contribute most to heart disease prediction

Hyperparameter Tuning: Finding optimal model parameters to improve performance
